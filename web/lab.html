MP4 Diff Lab

同一の MP4 bytes を Rust/WASM (固定コミットの参照実装 1282b704) と MoonBit/JS (本リポジトリ) で それぞれ解析し、観測値を field path 単位で突き合わせます。 判定は PASS / FAIL / UNVERIFIED / NOT_RUN を区別します (「差分なし」と「未検証」を混同しません)。

  • 解析はすべてブラウザ内で完結します。ファイルは外部に送信されません。
  • Rust 側は tools/lab-oracle (wasm32 cdylib) が全量読みで観測、 MoonBit 側は File.slice の Range I/O で観測します (mdat ペイロードは読みません)。
  • box tree は出現順が入力順と一致しない場合があるため順序非依存で比較し、 順序差は box_tree.order エントリとして分離します。
  • MP4 Dump デモへ戻る
MP4 ファイルをドラッグ&ドロップ、またはクリックして選択
